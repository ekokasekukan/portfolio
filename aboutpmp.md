В файле pmp.cpp лежит вариант профайлера бедного человека, написанный мной для курсовой. Это инструмент для анализа программ,
который работает с помощью gdb. Результатом программы является, файл который можно превратить в флеймграфик.
Чтобы запустить: 
 •сначала запуск тестовой программы в фоне - ./test 120 &
 •затем сам пбч (собирает стеки 15 секунд и пишет результат) - ./pmp $! -d 15 -i 100 -o profile.collapsed
Для построения графика:
./FlameGraph/flamegraph.pl profile.collapsed > flame.svg - этот файл открывается в браузере.
